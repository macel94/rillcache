# Rillcache v0.1.0 release notes

Release candidate notes for `v0.1.0`. These notes are the input to
`scripts/cut-release.sh`; the tag is created only by the release owner after every
gate passes.

## Candidate

- Version: `0.1.0` (`Cargo.toml`).
- Candidate commit: the `main` head that contains this file; the exact SHA is
  filled in by the release owner at tag time.
- Container images: `ghcr.io/macel94/rillcache` platform digests recorded by the
  container workflow for that SHA. No digest is claimed here before publication.

## Compatibility profile

The supported surface is the profile in `docs/compatibility.md` at this commit:
RESP2 and the documented RESP3 subset, the command inventory in
`docs/compatibility.md`, DB 0 only, standalone topology. Unsupported capabilities
are listed in `docs/unsupported.md` instead of being implied by silence.

## Changes

See `CHANGELOG.md` under `0.1.0`.

## Migration

None required from a previous tagged release: `0.1.0` is the first versioned
artifact. From an untagged `main` pre-release, replay the existing journal; if the
journal was written by an older format, dump and restore instead.

## Rollback

Rolling back to an untagged `main` build of the same journal format is supported.
Rolling back across a journal format change is unsupported and is called out per
release.

## Support window

Published policy (`docs/release-lifecycle.md`): stable MINOR releases are
supported for 12 months from the release date with PATCH fixes for security and
data-integrity defects; the previous MINOR is supported for 90 days after the next
MINOR ships; older releases are unsupported. Pre-releases carry no support
promise. This window starts on the date the release owner publishes the tag, not
before.
